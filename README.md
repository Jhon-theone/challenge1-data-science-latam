# Challenge Alura Store

## Analisis de ventas-Alura store

### Descripción del proyecto

Este proyecto forma parte de programa de estudios del programa **Oracle Next Education (ONE)** de **Alura LATAM**, donde el
objetivo es practicar y desarrolar habilidades en Analisis de datos. En este desafio se analizaron datos de ventas de 4 
empresas con el fin de analizar sus ingresos y tomar desiciones basado en ello. 
El análisis se realizó eutilizando la plataforma de Google Colab, utilizando técnicas básicas de análisis de datos y 
visualización de graficos para apoyar la toma de decisiones del cliente.

### Objetivo del Analisis

El señor Juan nos solicito resalizar un analisis de los ingresos y desempeño de sus de 4 de sus tiendas.
los a tomar en cuenta fueron:

- Ingreso total por cada tienda.
- La categorias mas vendidas.
- La calificación media de cada tienda.
- Los productos mas vendidos y los menos vendidos.
- El costo de envio por tienda.
